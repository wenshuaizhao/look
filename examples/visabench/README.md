# VisABench notebook samples

Four RefCOCO testA/testB referring expressions with their original COCO train2014 photographs. The IDs preserve the split, reference ID, and sentence ID. The images are copied unchanged; SHA-256 hashes are recorded in `samples.json`.

The mismatch expressions use the same pairing as the full VisABench evaluation. As in that evaluation, mismatched-expression labels are approximate: an expression from another image can occasionally also describe the current image.

Dataset source: https://huggingface.co/datasets/jxu124/refcoco
Photographs: https://cocodataset.org/
